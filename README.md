## 🌟 Overview

This repository contains a suite of web applications and browser-based tools designed to operate **100% client-side**. All file conversions, PDF unlocking, password encryption/decryption, document merging, page extraction, image conversions, and license generation happen directly within your browser without sending any data to external servers.

---

## 🛠️ Featured Applications

### 🔓 PDF Suite Pro & Unlocker (`PdfUnlock/PDF_Unlock.html`)
An all-in-one PDF utility suite equipped with 8 essential tools and direct `.ZIP` archive support.

| Tool | Feature Description |
| :--- | :--- |
| 🔓 **Unlock PDF** | Remove user passwords, printing, copying, and modification restrictions. Supports batch unlocking via single PDF files or `.ZIP` archives containing multiple PDFs with per-file custom password overrides. |
| 🧩 **Merge PDFs** | Combine multiple PDFs into a single document with interactive HTML5 drag-and-drop reordering. |
| 🗜️ **Compress PDF** | Reduce file sizes with an interactive percentage quality slider (10% to 90% strength) and live size reduction stats. |
| ✂️ **Extract Pages** | Extract page ranges (e.g. `1-3, 5, 8-10`) or visually click page thumbnails in an interactive page selector grid. |
| 🌐 **HTML to PDF** | Convert HTML code or formatted web documents into crisp PDF files with live preview. |
| 🔒 **Protect PDF** | Add user passwords and owner permissions encryption. |
| 🔄 **Rotate PDF** | Rotate pages 90°, 180°, or 270° (All, Odd, or Even pages). |
| 🖼️ **Image to PDF** | Convert JPG, PNG, and WebP images to customizable PDF documents. |

> 🎨 **Adaptive Theme & Preferences**: Features a 3-mode theme switcher (System Auto OS Theme, Dark Mode, Light Mode) and saves user preferences locally in `localStorage`.

### 🏷️ SKU PDF Sorter Pro (`PdfSorter/index.html`)
Premium PDF document sorting tool designed for e-commerce, order processing, and SKU label organization.
- Automatic SKU text extraction & matching using `pdf.js`.
- Custom sorting rules, label re-ordering, and batch page compilation.

---

### 🌿 Farm Fresh License Portal (`index.html`)
Internal POS biller license key generator utilizing CryptoJS AES-128/256 CBC encryption.
- Auto-generates long-term device activation keys.
- Fast one-tap copy to clipboard with toast notifications.

- ⚡ **Zero Setup Required**: No Node.js, backend server, or dependencies to install.

## 🚀 Getting Started

No build step or server installation is required. All applications are self-contained HTML single-page web applications.

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/your-username/Mayur.git
   ```
2. **Launch Any Application**:
   Simply open any `.html` file directly in your web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari).
